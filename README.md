# SupplyHouse Storefront

A Next.js ecommerce storefront for plumbing and HVAC products.

## What it does

- Shows only Plumbing and HVAC categories
- Lets users add mock products to a client-side cart
- Keeps checkout contact-first instead of payment-first
- Surfaces customer care details prominently in the cart flow

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
